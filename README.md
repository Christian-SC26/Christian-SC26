## 👋 About me

I build iOS apps. For 7+ years I have done it inside Big Tech: large codebases, dozens of engineers in one repo, release trains, and users who notice a dropped frame.

- 📱 **iOS first.** Swift and SwiftUI today, UIKit and Objective-C where the app grew up.
- 🖥️ **macOS on the side.** I maintain a fork of [yabai](https://github.com/Christian-SC26/yabai), a tiling window manager that hooks into the macOS window server, and keep it running on macOS 27.
- ⚙️ **Close to the metal.** When a problem lives below the UI layer I drop into C, C++, Objective-C runtime tricks, or Rust.
- 🧪 **Testing and tooling.** I write the scripts, Homebrew taps and agent skills that keep my team and me fast.
